## 🎯 Sobre o Projeto

O **To-Do List Pro** é uma aplicação web interativa, desenvolvida para ser sua ferramenta de organização diária. O objetivo foi criar uma interface limpa, intuitiva e funcional, onde o gerenciamento de tarefas fosse rápido e sem complicações.

Este projeto foi uma ótima oportunidade para praticar a manipulação do DOM com JavaScript e o armazenamento de dados localmente no navegador.

## ✨ Funcionalidades Principais

-   **Adicionar Tarefas:** Campo de texto para adicionar novas tarefas à sua lista de forma rápida.
-   **Marcar como Concluído:** Clique em uma tarefa para riscá-la, mostrando o que já foi feito.
-   **Remover Tarefas:** Botão para excluir tarefas que não são mais necessárias.
-   **Filtros de Visualização:** Alterne entre ver todas as tarefas, apenas as ativas ou as já concluídas.
-   **Persistência de Dados:** Suas tarefas são salvas no _Local Storage_ do navegador, então você não perde nada ao fechar a página!
